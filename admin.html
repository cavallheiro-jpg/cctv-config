Conexão com o GitHub

Como criar o token (uma vez só)
  1. No GitHub, toque na sua foto > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Em "Repository access", escolha "Only select repositories" e marque só cctv-config.
  3. Em "Permissions" > Repository permissions, deixe Contents como "Read and write".
  4. Gere o token e cole acima. Ele só vale para esse repositório.
